# chess-coach

Личная шахматная тренерская на Claude Code. Stockfish считает, Claude объясняет, ведёт программу и помнит твои слабости.

## Запуск

```bash
cd chess-coach
claude
```

Первое сообщение: **«Прочитай SETUP.md и выполни установку»**. Потом: **«Давай первое занятие»**, это запустит скилл `build-profile`.

Дальше просто разговаривай: «разбери последнюю партию», «вот ссылка: …», «что мне тренировать на этой неделе».

## Что внутри

- `coach/` — CLI на python-chess: импорт партий, анализ, разбор, статистика, доска, отчёты. Справка: `uv run coach --help`.
- `CLAUDE.md` — роль и правила тренера.
- `.claude/skills/` — сценарии занятий.
- `profile/player.md` — твоя модель как игрока, растёт с каждым разбором.
- `ROADMAP.md` — этапы 2–4: живая доска, Maia-2, задачи и дебюты, платформа.

`data/` и `profile/` содержат личные данные. Если будешь выкладывать репозиторий, исключи их.
